# 🌤️ Weather Prediction App – JavaScript Weather Application

🔗 **Live Demo:** https://weatherpredictionayushd172005.vercel.app/

A responsive **Weather Prediction Web App** built using **HTML, CSS, and Vanilla JavaScript**, integrated with the **OpenWeather API** to fetch real-time weather data.  
This project demonstrates strong **API integration**, **asynchronous JavaScript**, and **frontend development fundamentals**.

---

## 📌 Project Overview

The Weather Prediction App allows users to search for any city worldwide and view **live weather information**, including temperature, weather conditions, humidity, and wind speed.  
The application handles **error states gracefully** and dynamically updates the UI without page reloads.

This project is ideal for showcasing **real-world API usage** and **frontend problem-solving skills** to recruiters and ATS systems.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature (°C)
- 🌥️ Weather condition and description
- 💧 Humidity level
- 💨 Wind speed
- 🖼️ Dynamic weather icons
- ❌ Error handling for invalid city names
- 📱 Fully responsive UI (mobile & desktop)

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup
- **CSS3** – Responsive styling and layout
- **JavaScript (ES6)** – API calls, DOM manipulation, async/await
- **OpenWeather API** – Live weather data
- **Vercel** – Deployment and hosting
